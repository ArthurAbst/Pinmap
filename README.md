# Pinmap — контурная карта мира с кнопками, фото и заметками

Прототип: всё работает в браузере, без сервера и без сторонних картографических сервисов.

**Сайт: https://arthurabst.github.io/Pinmap/** (GitHub Pages, обновляется через 1–2 минуты после каждого push в `main`).

## Запуск

Нужен любой статический веб-сервер (если открыть `index.html` двойным кликом, браузер не даст загрузить данные).

```bash
cd pinmap
python3 -m http.server 8000      # или: npx serve .
# открыть http://localhost:8000
```

## Что уже есть

- Контурная карта мира (проекция Natural Earth, D3 + Canvas): страны, границы, реки, озёра, моря, горные хребты, пустыни, вершины, ~7300 городов, 116 природных достопримечательностей. Подписи появляются по мере приближения, от зума ~4 подгружается детальный слой 1:10m.
- Кнопки трёх типов: Visited / Want to go / Label only (последний — просто подпись на карте, без кнопки). Страны с посещёнными местами закрашиваются (страна определяется и для точек у самого берега).
- Предпросмотр: наведение (компьютер) или тап (телефон) по кнопке показывает небольшую карточку с листаемыми фото; «Open place» открывает редактирование.
- Стартовый вид: последний вид на этом устройстве, иначе все ваши кнопки, иначе карта мира на весь экран.
- Карточка места: название, когда был (месяц и год, например «June 2026»; поездок может быть несколько), заметки, фото (сжимаются в браузере до 2048 px плюс миниатюра), галерея на весь экран.
- Импорт фото: кнопка «Add photos» вверху или перетаскивание файлов на карту. Из EXIF читаются координаты и дата, фото группируются по месту (радиус ~12 км), рядом с существующей кнопкой (до 25 км) предлагается добавить туда. Фото без геометки: «Choose on map» (клик по карте, по кнопке или поиск) или выбор из своих мест. Дата из фото сама становится «When».
- Поиск: локальный индекс (страны, водоёмы, рельеф, достопримечательности, ~112 тыс. населённых пунктов из GeoNames) плюс кнопка «Search OpenStreetMap» для всего остального (Nominatim).
- Список мест по странам, статистика, экспорт и импорт резервной копии в JSON.
- Светлая и тёмная тема, мобильная раскладка.

## Как устроена отрисовка (почему карта плавная)

- Геометрия проецируется один раз и режется на квадраты 50×50 «мировых единиц» (Path2D + рамка), рисуются только видимые квадраты.
- Полная отрисовка (контуры + подписи) идёт в невидимый «снимок», который на 30% больше экрана. Во время перетаскивания и зума снимок только масштабируется и сдвигается одной командой, кнопки рисуются поверх вживую. Чёткая перерисовка — когда жест закончился, или раньше, если снимок слишком размылся или кончился запас по краям.
- Подписи проверяются на наложение через сеточный индекс.
- В консоли браузера: `__map.bench()` — время полной отрисовки в мс, `__map.benchComposite()` — время кадра во время жеста.

## Выложить для друзей

Приложение полностью статическое, подойдёт любой хостинг статики:
- **Netlify Drop**: app.netlify.com/drop, перетащить папку `pinmap`, затем завести бесплатный аккаунт и нажать «Claim» — иначе сайт удалится. Обновление — перетащить новую папку в панели сайта.
- **Cloudflare Pages / GitHub Pages** — аналогично, бесплатно.

У каждого друга данные хранятся в его собственном браузере: аккаунтов пока нет, общих карт тоже.

## Где хранятся данные

В IndexedDB браузера (`js/store.js`): места и фото живут только в этом браузере на этом компьютере. **Регулярно делайте Export backup.** Чтобы перейти на сервер (аккаунты, обмен картами), достаточно заменить `store.js` на версию с API, остальной код его не трогает.

## Структура

```
index.html, style.css
js/app.js      — интерфейс: всплывающее окно, карточка, список, поиск, фото
js/map.js      — отрисовка карты, подписи, кнопки, зум, клики
js/search.js   — локальный поиск + Nominatim
js/store.js    — IndexedDB (заменить на API для мультипользовательской версии)
data/world50.json   — карта 1:50m (TopoJSON)
data/world10.json   — детальная карта 1:10m (грузится при приближении)
data/labels.json    — подписи: страны, города, рельеф, водоёмы, достопримечательности
data/gazetteer.json — населённые пункты для поиска (GeoNames, население от 1000)
scripts/build_labels.py — сборка labels.json и gazetteer.json
```

## Пересборка данных

```bash
./scripts/build_data.sh   # скачает Natural Earth, соберёт TopoJSON, подписи и индекс поиска
```
Список достопримечательностей — `scripts/landmarks.json`, формат `[name, kind, lon, lat]`; координаты приблизительные, их легко дополнить.
